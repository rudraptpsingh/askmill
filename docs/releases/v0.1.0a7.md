# AskMill 0.1.0a7 candidate

Adds explicitly registered local embeddings via `askmill embed` and the
`askmill.embedding` SDK. The engine pins a host-selected encoder model, tokenizer,
provider/runtime and exact requests; acquires configured shared leases; runs one
bounded batch and one cleanup request through an owned local service; validates
actual token counts, context, finite normalized Float32 rows and resource
settlement; and delegates current opaque-scope authorization and a durable
single-use budget to a separately authenticated host gate. Existing generation
profiles and installations are not migrated.

The registered profile entry's canonical JSON hash is reported separately from
the profile file-byte hash. New implementations require new provider/profile
identities; matching cached weights or dimensions alone does not authorize reuse
of an older vector namespace. Query/Backend own private source authorization,
typed response translation and live consumer acceptance.

The candidate passed 33 affected source tests and 11 isolated installed-wheel
software controls; the existing tokenizer metadata was checked on a synthetic
string without loading a model. No actual embedding, model loading, provider
startup or consumer acceptance occurred. Independent lifecycle/security review
and current authorized host gate, registered profile and exact input refs are
required before use. No source quality, legal or semantic acceptance is implied.
See [embedding setup](../EMBEDDINGS.md).
